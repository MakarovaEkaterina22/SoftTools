# Практические работы

Папка для ноутбуков и материалов практических работ по SoftTools.

Чтобы загрузить работу: откройте эту папку → Add file → Upload files → Commit changes.

Чтобы создать вложенную папку: Add file → Create new file, укажите имя вида `ПР1/README.md`, добавьте описание и сохраните через Commit changes.
